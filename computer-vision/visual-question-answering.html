Visual Question Answering: Models, Benchmarks, and Evaluation

Visual Question Answering (VQA) requires a model to answer natural-language questions about a given image. Unlike image classification, VQA demands joint reasoning over visual and linguistic structure, probing spatial, relational, counting, and commonsense understanding that emerges from combining heterogeneous modalities across diverse real-world scenarios.

VQA datasets contain image-question-answer triples collected via crowdsourcing. Early benchmarks like VQAv1 revealed that models exploit statistical biases in question phrasing — answering 'yes' to most yes/no questions without examining the image. VQAv2 addressed this by pairing each image with a complementary image to balance answer distributions and force genuine visual reasoning.

The VQA task is formally defined as: given image I and question Q, predict answer a from a candidate set. In classification-style VQA, the answer space is a closed vocabulary of K frequent answers — typically the 3,000 most common across training data — scored by a joint visual-textual representation learned end-to-end from image-question-answer supervision.

Open-ended VQA uses a generative decoder that produces free-form text rather than selecting from a fixed vocabulary. This allows models to handle rare or never-seen answers but requires softer evaluation metrics such as CIDEr or BERTScore. Models like BLIP-2 condition a frozen large language model decoder on image tokens projected through a lightweight Q-Former bridge.

image_feat = vit(image)\ntext_feat = bert(question)\nfused = image_feat + cross_attn(image_feat, text_feat)\nlogits = classifier(fused)\npred = answer_vocab[logits.argmax()]

The dominant VQA architecture pairs a visual encoder — usually a Vision Transformer — with a text encoder such as BERT. Features from both modalities are fused through cross-attention layers that allow each modality to query the other. The resulting joint representation feeds a classification head that scores each candidate answer in the closed answer vocabulary.

More recent architectures use a Q-Former bridging module, as in BLIP-2, that extracts a fixed set of visual query tokens from the image encoder and injects them into a frozen large language model. This decouples training: only the lightweight bridge is updated while both the image backbone and the LLM remain frozen, dramatically reducing compute cost and enabling fast adaptation.

inputs = processor(image, question, return_tensors="pt")\nout = model.generate(**inputs, max_new_tokens=20)\nanswer = processor.decode(out[0], skip_special_tokens=True)

Dataset bias in VQA arises when question-answer pairs carry strong statistical priors independent of image content. The question 'What sport is being played?' predominantly maps to 'tennis' across multiple VQA benchmarks. Models learn these priors and can achieve surprisingly high accuracy without performing genuine visual reasoning at inference time.

OK-VQA and TextVQA were introduced to reduce superficial language bias by requiring external commonsense knowledge or reading text embedded in the image. DocVQA focuses on document-understanding questions where answers must be extracted from structured document layouts. Each benchmark exposes distinct failure modes that standard VQAv2 evaluation does not capture.

# each question has 10 human answers\nacc = min(count_matching / 3, 1.0)\n# avg over all questions

****: VQA models frequently exploit dataset biases — 'What color is the banana?' answers 'yellow' without looking at the image. Always run blind-model baselines; if accuracy > 40%, your evaluation overstates visual understanding.

Open-ended VQA is evaluated using VQA soft accuracy: a model answer earns full credit if at least 3 of 10 human annotators gave the same answer, and partial credit otherwise. This design rewards predicting the modal human response but penalizes lexically different paraphrases that carry the exact same meaning as the reference answers in the annotation set.

Multiple-choice VQA provides 4 or 5 candidate answers per question, simplifying evaluation by eliminating the need for soft matching metrics. However, models can identify correct answers by exploiting plausibility contrasts among distractors rather than reasoning from the image, which means MC scores often correlate poorly with open-ended generalization capability.

VQA benchmarks drive significant progress in multimodal architectures, but blind-model baselines remain essential for validating that gains reflect genuine visual reasoning. Always evaluate a question-only model before attributing accuracy improvements to visual understanding rather than exploitation of statistical language priors embedded in the benchmark answer distribution.

Generative VQA models outperform classification heads on open-ended and knowledge-intensive benchmarks such as OK-VQA and DocVQA, but require significantly more compute and careful decoding strategies. BLIP-2 and InstructBLIP establish the current state of the art by connecting frozen visual and language encoders through a lightweight trainable Q-Former bridge module.

For production VQA systems, match the model type to your answer distribution. Classification-style models are faster and more precise for constrained answer spaces such as product attributes or form fields. Generative models handle open-domain and knowledge-intensive questions better but require robust output parsing and answer verification for reliable downstream integration.
