DeiT: Data-Efficient Image Transformers via Distillation

Overview

Vision Transformer (ViT) achieves state-of-the-art accuracy but requires pre-training on hundreds of millions of images (JFT-300M). DeiT — Data-efficient Image Transformers — addresses this bottleneck by training a transformer on ImageNet-1K alone (1.28M images) and reaching competitive accuracy through knowledge distillation from a CNN teacher model.

DeiT introduces a dedicated distillation token — a learnable vector appended alongside the class token to the patch sequence. This token is supervised not by the ground-truth label but by the teacher model's output, enabling the student transformer to absorb convolutional inductive biases such as local feature hierarchies and translation equivariance.

The approach is training-efficient: no proprietary dataset, no extra inference overhead, and the distillation token can be discarded at runtime in favour of the class token or a simple average of both. DeiT-B distilled matches ViT-B fine-tuned from JFT-300M while training only on public ImageNet-1K in under three days on 8 V100 GPUs.

Distillation Token

The standard ViT prepends a single [CLS] learnable embedding to the sequence of flattened patch projections. DeiT adds a second learnable embedding called the distillation token [DIST]. Both tokens attend to all patches and to each other through every transformer layer, accumulating globally mixed representations before the output heads.

import torch
import torch.nn as nn

class DeiT(nn.Module):
    def __init__(self, embed_dim=768, num_classes=1000):
        super().__init__()
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.dist_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.head = nn.Linear(embed_dim, num_classes)
        self.head_dist = nn.Linear(embed_dim, num_classes)
    def forward(self, patches):
        B = patches.shape[0]
        cls = self.cls_token.expand(B, -1, -1)
        dist = self.dist_token.expand(B, -1, -1)
        return torch.cat([cls, dist, patches], dim=1)

At inference time, DeiT produces two logit vectors — one from the class head, one from the distillation head. The authors recommend averaging these as the final prediction. The distillation head alone achieves slightly higher top-1 than the class head, evidence that the token has effectively internalised the CNN teacher's spatial priors.

Hard and Soft Distillation

Hard-label distillation treats the teacher's argmax prediction as a hard pseudo-label. The total loss splits equally: half is cross-entropy between student class logits and the true one-hot label; half is cross-entropy between student distillation logits and the teacher's hard decision. No temperature is involved, making this the simpler variant.

import torch.nn.functional as F

def hard_distillation_loss(student_cls_logits, student_dist_logits,
                            labels, cnn_teacher, images):
    teacher_pred = cnn_teacher(images).argmax(-1)
    dist_loss = F.cross_entropy(student_dist_logits, teacher_pred)
    cls_loss  = F.cross_entropy(student_cls_logits, labels)
    total = 0.5 * cls_loss + 0.5 * dist_loss
    return total

Soft distillation replaces the teacher's hard argmax with its full softmax distribution scaled by temperature τ, forming a smoother probability vector that reveals class similarity. The distillation branch minimises KL-divergence between the student's soft output and this smoothed teacher distribution, weighted by α and scaled by τ² for gradient magnitude.

import torch.nn.functional as F

def soft_distillation_loss(cls_logits, dist_logits, teacher_logits,
                            labels, tau=3.0, alpha=0.5):
    soft_teacher = F.softmax(teacher_logits / tau, dim=-1)
    kl = F.kl_div(F.log_softmax(dist_logits / tau, dim=-1),
                  soft_teacher, reduction='batchmean')
    ce = F.cross_entropy(cls_logits, labels)
    total = (1 - alpha) * ce + alpha * (tau ** 2) * kl
    return total

Training Recipe

DeiT's training recipe is heavy on regularisation and augmentation to compensate for the smaller dataset. The default schedule trains for 300 epochs with a cosine learning-rate schedule and linear warmup. AdamW is used with decoupled weight decay of 0.05 and gradient clipping, making training stable at large batch sizes without learning-rate scaling hacks.

training_config = dict(
    epochs=300,
    batch_size=1024,
    optimizer='AdamW',
    lr=1e-3,
    weight_decay=0.05,
    stochastic_depth=0.1,
    repeated_aug=True,
    rand_augment='rand-m9-mstd0.5',
    mixup_alpha=0.8,
    cutmix_alpha=1.0,
    warmup_epochs=5,
    lr_schedule='cosine',
)

Repeated augmentation samples each image multiple times per batch, exposing the model to correlated but varied views and effectively acting as dataset expansion. RandAugment applies a sequence of random photometric and geometric transforms; Mixup and CutMix blend pairs of training examples, while stochastic depth randomly drops transformer layers during training.

****: DeiT's key finding: the distillation token learns from the CNN teacher's inductive biases (locality, translation invariance) that ViT lacks. Classifying via the distillation token alone outperforms the class token on many downstream tasks.

DeiT vs ViT

DeiT variants span three sizes — Tiny, Small, and Base — parameterised by embedding dimension and number of attention heads. All variants follow the same distillation regime with a RegNetY-16GF CNN teacher (84M params). The Base variant is architecturally identical to ViT-B/16, enabling a direct apples-to-apples accuracy comparison at the same parameter count.

The distilled DeiT-B↑384 model achieves 85.2% top-1, surpassing ViT-B/16 fine-tuned on JFT by over 1 point and remaining competitive with convolutional networks of similar capacity. Throughput stays high because the architecture adds no extra layers — only an additional head and one embedding token, costing negligible FLOPs compared to patch projection and attention.

Key Takeaways

Knowledge distillation can substitute for large-scale pretraining: DeiT demonstrates that the data-hunger of vision transformers is not fundamental but arises from a lack of convolutional inductive biases. Injecting these biases via a CNN teacher allows a pure transformer to learn meaningful representations from ImageNet-1K alone without JFT pretraining.

The distillation token is architecturally minimal but functionally significant. Its dedicated head is supervised on teacher outputs while the class head remains supervised on true labels, creating two complementary views of the input. Combining both heads at inference reliably outperforms using either head in isolation across standard classification benchmarks.

DeiT's training recipe — AdamW, strong augmentation, repeated sampling, stochastic depth — became a template for subsequent vision transformer work including Swin and DeiT-III. The recipe matters as much as the architecture: applying it to plain ViT-B without distillation already closes a significant fraction of the accuracy gap versus CNN baselines on ImageNet.
