Transfer Learning in Computer Vision

Transfer learning reuses weights from a model trained on a large dataset (typically ImageNet-1K or ImageNet-21K) as a starting point for a new task. The intuition is that low-level features — edges, textures, gradients — are universal across vision tasks, while higher-level features become increasingly task-specific. This approach dramatically reduces the data and compute needed for new tasks.

Models pretrained on ImageNet learn a rich hierarchy of visual concepts: early layers detect edges and colors, middle layers capture shapes and parts, and final layers encode high-level semantics like objects and scenes. Even when the target domain differs from natural images, these learned representations outperform random initialization unless you have millions of in-domain samples.

Linear probing freezes all pretrained weights and trains only a new classification head on top of the fixed backbone. This is the simplest transfer strategy: the backbone acts as a fixed feature extractor. Because no backbone weights change, training is fast and cheap, and the approach works well when the target domain is similar to the pretraining domain.

import torch\nimport torchvision.models as models\n\nmodel = models.resnet50(weights="IMAGENET1K_V2")\nfor param in model.parameters():\n    param.requires_grad = False\n\nnum_classes = 100\nmodel.fc = torch.nn.Linear(model.fc.in_features, num_classes)\n\noptimizer = torch.optim.Adam(model.fc.parameters(), lr=1e-3)

Linear probing accuracy depends heavily on feature quality. ViT-L/14 features from CLIP achieve over 76% top-1 on ImageNet with a single linear layer. ResNet-50 ImageNet features typically reach 55–60% on CIFAR-100. The gap between linear probe and fine-tuned performance reveals how well the pretrained representation aligns with the target task distribution.

Full fine-tuning unfreezes the entire backbone and trains all weights end-to-end. A critical trick is using a much smaller learning rate for backbone layers than for the newly initialized head — typically 10× lower. Without this asymmetry, large gradient updates destroy the pretrained representations before the new head learns meaningful signals from them.

import torch\nimport torchvision.models as models\n\nmodel = models.resnet50(weights="IMAGENET1K_V2")\nnum_classes = 100\nmodel.fc = torch.nn.Linear(model.fc.in_features, num_classes)\n\nbackbone_params = [p for n, p in model.named_parameters() if "fc" not in n]\nhead_params = list(model.fc.parameters())\n\noptimizer = torch.optim.SGD([\n    {"params": backbone_params, "lr": 1e-4},\n    {"params": head_params,     "lr": 1e-3},\n], momentum=0.9, weight_decay=1e-4)

Full fine-tuning is most effective when you have ≥10K labeled samples and when the target domain differs meaningfully from ImageNet (e.g., satellite imagery, medical scans, industrial defects). With too little data, fine-tuning overfits quickly. Regularization strategies like weight decay, dropout, label smoothing, and data augmentation are essential to prevent overfitting on small datasets.

Layer-wise learning rate decay (LLRD) assigns progressively smaller learning rates to earlier network layers. The intuition is that early layers learn generic features that should barely change, while later layers learn task-specific patterns that need more adaptation. LLRD is a refinement of the two-group approach and is the standard recipe for fine-tuning large vision transformers like ViT.

def get_llrd_params(model, base_lr=1e-3, decay=0.75):\n    layers = list(model.named_parameters())\n    total = len(layers)\n    param_groups = []\n    for idx, (name, param) in enumerate(layers):\n        lr = base_lr * (decay ** (total - idx))\n        param_groups.append({"params": [param], "lr": lr, "name": name})\n    return param_groups\n\nparam_groups = get_llrd_params(model, base_lr=1e-3, decay=0.75)\noptimizer = torch.optim.AdamW(param_groups, weight_decay=0.05)

In practice, decay values between 0.65 and 0.85 work well for most ViT models. For ResNet-style backbones, grouping by layer block (layer1 through layer4) rather than individual parameters is more common. Research on BERT-style NLP models originally established this technique; it transferred to vision transformers with similar gains, typically improving fine-tuned accuracy by 1–3% over uniform LR.

Domain gap measures how different the target distribution is from the pretraining distribution. A small gap (e.g., fine-grained bird classification vs. ImageNet) allows aggressive transfer with minimal modification. A large gap (e.g., histopathology slides, remote-sensing imagery, X-rays) may require intermediate pretraining on an unlabeled in-domain corpus before supervised fine-tuning.

Three strategies address large domain gaps: (1) Domain-adaptive pretraining — continue masked image modeling on unlabeled target-domain data before fine-tuning. (2) Multi-source transfer — pretrain on a mix of ImageNet and a domain-adjacent dataset. (3) Feature alignment — use adversarial training or MMD loss to align source and target feature distributions at intermediate layers.

Transfer learning is the default starting point for nearly all practical computer vision projects. ImageNet pretraining provides strong inductive biases even for non-natural-image domains. The choice of transfer strategy should be driven by dataset size, domain similarity, and compute budget — not by intuition alone. Always establish a linear probe baseline before committing to full fine-tuning.

Modern best practices: use the largest pretrained model your inference budget allows, apply layer-wise LR decay for transformers, warm up the learning rate for 5–10% of training, and use strong augmentations (RandAugment, MixUp, CutMix) to regularize fine-tuning. Monitor both training and validation loss curves; early divergence between them signals overfitting on insufficient data.
