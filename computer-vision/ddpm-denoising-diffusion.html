DDPM: Denoising Diffusion Probabilistic Models

Overview

Denoising Diffusion Probabilistic Models (DDPM) introduced a principled generative framework using a Markov chain that gradually corrupts data with Gaussian noise, then learns to reverse the process. Published by Ho et al. (2020), DDPM matched GAN image quality without adversarial training, establishing diffusion models as a viable generative paradigm.

The model defines two processes: a fixed forward process q that destroys signal by adding noise over T steps, and a learned reverse process p_theta that reconstructs data from pure noise. A U-Net backbone conditioned on timestep embeddings serves as the denoising network, achieving FID 3.17 on CIFAR-10 and high-quality samples on CelebA-HQ.

Forward Noising Process

The forward process applies a fixed Markov chain with variance schedule beta_1,...,beta_T where beta_t in (0,1). Each step adds Gaussian noise: q(x_t|x_{t-1})=N(sqrt(1-beta_t)x_{t-1}, beta_tI). Defining alpha_bar_t as the cumulative product of (1-beta_s) gives the closed-form q(x_t|x_0)=N(sqrt(alpha_bar_t)x_0, (1-alpha_bar_t)I).

import torch\nT = 1000\nbetas = torch.linspace(1e-4, 0.02, T)\nalphas = 1.0 - betas\nalphas_bar = torch.cumprod(alphas, dim=0)\n\ndef forward_noise(x0, t, noise):\n    ab = alphas_bar[t].view(-1, 1, 1, 1)\n    return ab.sqrt() * x0 + (1 - ab).sqrt() * noise

The linear schedule ranges from beta=1e-4 to 0.02, ensuring x_T approximates N(0,I). A cosine schedule from iDDPM avoids abrupt noise increase early in the sequence, improving low-resolution generation quality. The reparameterization x_t = sqrt(alpha_bar_t)x_0 + sqrt(1-alpha_bar_t)eps enables efficient single-step sampling at any timestep.

Reverse Denoising Process

The reverse process p_theta(x_{t-1}|x_t) approximates the true posterior q(x_{t-1}|x_t,x_0), which is a Gaussian with tractable closed-form mean. Because the marginal posterior over x_0 is intractable, the model instead predicts noise eps_theta(x_t,t) and computes the denoised mean analytically. Variance is fixed to the forward schedule values.

def ddpm_step(model, x_t, t, betas, alphas_bar):\n    alpha_t = 1.0 - betas[t]\n    abar_t  = alphas_bar[t]\n    eps     = model(x_t, t)\n    mu = (x_t - betas[t] / (1 - abar_t).sqrt() * eps) / alpha_t.sqrt()\n    z  = torch.randn_like(x_t) if t > 0 else torch.zeros_like(x_t)\n    return mu + betas[t].sqrt() * z

Noise z ~ N(0,I) is injected at every step except t=0, preserving the stochastic Markov structure. The intermediate estimate x0_pred = (x_t - sqrt(1-alpha_bar_t)*eps) / sqrt(alpha_bar_t) can be monitored during sampling. Full generation requires T=1000 sequential U-Net evaluations, making vanilla DDPM slow at inference time.

Training Objective

DDPM maximizes the ELBO on log p_theta(x_0), decomposing into a reconstruction term and T-1 KL divergences between forward and reverse posteriors at each step. Ho et al. found that a reweighted simplified objective — minimizing MSE between predicted and actual noise — significantly outperforms the full ELBO and x_0 prediction alternatives.

import torch.nn.functional as F\n\ndef training_step(model, x0, T, alphas_bar):\n    B = x0.shape[0]\n    t     = torch.randint(0, T, (B,), device=x0.device)\n    noise = torch.randn_like(x0)\n    x_t   = forward_noise(x0, t, noise)\n    loss  = F.mse_loss(model(x_t, t), noise)\n    return loss

Timestep t is sampled uniformly during training so the model learns denoising across all noise levels equally. The U-Net receives x_t and a sinusoidal embedding of t analogous to transformer positional encodings. Training follows AdamW at lr=2e-4 with no learning rate schedule, converging stably over millions of gradient steps without GAN-style instability.

info: DDPM's training objective simplifies to predicting the added noise (epsilon-parameterization), which is equivalent to maximizing the ELBO but much easier to optimize. This simplification was the key insight enabling stable training.

DDIM Accelerated Sampling

Denoising Diffusion Implicit Models (DDIM) by Song et al. redefine the reverse process using a non-Markovian family of distributions that share the same marginals as DDPM. This allows using any subset of timesteps without retraining, enabling 10-50x speedup at inference. DDIM uses the same trained checkpoint — no fine-tuning required.

def ddim_step(eps, x_t, t, t_prev, alphas_bar, eta=0.0):\n    ab_t    = alphas_bar[t]\n    ab_prev = alphas_bar[t_prev]\n    x0_pred = (x_t - (1 - ab_t).sqrt() * eps) / ab_t.sqrt()\n    sigma   = eta * ((1-ab_prev)/(1-ab_t)).sqrt() * (1 - ab_t/ab_prev).sqrt()\n    dir_xt  = (1 - ab_prev - sigma**2).sqrt() * eps\n    return ab_prev.sqrt() * x0_pred + dir_xt + sigma * torch.randn_like(x_t)

Setting eta=0 makes DDIM fully deterministic: identical initial noise always produces identical images, enabling meaningful latent space interpolation. Reducing from 1000 to 50 steps incurs only modest FID degradation. DPM-Solver and DEIS further improve efficiency by treating the reverse process as an ODE and applying higher-order numerical integration.

Key Takeaways

DDPM unified score matching, variational inference, and Langevin dynamics under a single training objective. The epsilon-parameterization — predicting added noise rather than the original image — proved simpler, more stable, and higher quality than x_0 prediction or score-based objectives. This design choice is preserved in virtually every subsequent diffusion architecture.

Unlike GANs, diffusion models train without adversarial instability or mode collapse. Unlike VAEs, they produce sharp samples without posterior collapse. The principal trade-off is inference cost: T sequential U-Net passes per sample. DDIM and ODE-based samplers have largely resolved this bottleneck, enabling real-time generation at industrial scale.

DDPM's probabilistic framework extends naturally to conditional generation via classifier guidance, classifier-free guidance, and ControlNet structural conditioning. Every major text-to-image model — Stable Diffusion, DALL-E 2, Imagen, Flux — inherits DDPM's forward process and epsilon-prediction objective, making DDPM the essential starting point.
