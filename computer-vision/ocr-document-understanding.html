Text Detection

# CRAFT text detector\nscore_map, affinity_map = craft(image)\n# Threshold score map for character regions\nchar_mask = score_map > 0.7\n# Link characters into words using affinity map\nboxes = watershed(char_mask, affinity_map)\n# boxes are word-level bounding boxes\nfor box in boxes:\n    x1, y1, x2, y2 = box\n    word_crop = image[y1:y2, x1:x2]

Text Recognition (CTC and Attention)

# CTC decoder\nlog_probs = ctc_model(image_crop)  # shape: (T, C)\npred_ids = ctc_decode(log_probs, blank=0)\n# Remove blank tokens and collapse repeated characters\ntext = ''.join([alphabet[i] for i in pred_ids if i != 0])\nprint(f'Recognized text: {text}')

Document VQA

# DocVQA with LayoutLM\n# Encode image patches + text tokens + bounding box coords\ninputs = processor(\n    image, question,\n    return_tensors='pt',\n    padding='max_length'\n)\noutputs = model(**inputs)\nstart = outputs.start_logits.argmax()\nend   = outputs.end_logits.argmax()\nanswer = processor.decode(inputs.input_ids[0][start:end+1])

info: Modern end-to-end models like Donut skip OCR entirely — they read documents directly as image patches and generate answers autoregressively. This avoids OCR error propagation but requires document-specific fine-tuning.
