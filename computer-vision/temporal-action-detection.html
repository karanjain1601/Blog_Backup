Temporal Action Detection: Localizing Actions in Untrimmed Video

Temporal action detection (TAD) identifies when specific actions occur in long, untrimmed videos, outputting temporal segments with class labels and confidence scores. Unlike trimmed action recognition, TAD must handle irrelevant background frames, variable action lengths from seconds to minutes, and overlapping actions — making it significantly harder than classifying pre-cut clips.

The field evolved from sliding-window classifiers over handcrafted features to end-to-end deep networks. Modern approaches process entire videos as 1-D temporal feature sequences using 2D (RGB frames) or 3D (spatiotemporal) CNNs as backbone encoders, then apply detection heads borrowed from image object detection — anchors, proposals, or dense prediction at every temporal position.

Temporal proposal methods generate candidate action segments before classification. The sliding window approach evaluates clips at multiple timescales, but is computationally expensive and misses fine-grained boundaries. Learned proposal networks like BMN predict start and end probabilities at each frame, then match high-confidence boundary pairs via a 2-D confidence map over all start-end combinations.

# Sliding window proposal generation\nfor t in range(0, T - win, stride):\n    clip = features[t : t + win]\n    score = classifier(clip)\n    if score > thresh:\n        proposals.append((t, t + win, score))

The key challenge in proposal generation is recall vs. efficiency. Dense sliding windows achieve high recall but flood downstream classifiers with proposals. Learned networks like BMN and BSN reduce proposal count while maintaining over 95% recall by focusing on high-confidence boundary pairs. Proposal quality measured by AR@AN (Average Recall at N proposals) directly drives downstream detection mAP.

Two-stage methods first generate temporal proposals, then classify and refine them. Stage one extracts features and predicts candidate segments. Stage two classifies each proposal using a separate head — often a pooled feature vector fed to a linear classifier. This decoupling allows flexible backbone choices and separate optimization of proposal quality and classification accuracy across training.

# Temporal IoU between two predicted segments\ndef temporal_iou(s1, e1, s2, e2):\n    intersection = min(e1, e2) - max(s1, s2)\n    union = max(e1, e2) - min(s1, s2)\n    return max(0, intersection) / union

Temporal IoU thresholds of 0.5 and 0.7 determine true positives at evaluation time. A predicted segment must overlap the ground-truth by at least the threshold to count as a match. During NMS, tIoU suppresses redundant predictions: proposals overlapping a high-confidence detection by tIoU above 0.5 are removed, leaving one detection per action instance in the final ranked output.

G-TAD improves two-stage pipelines by building a temporal graph over proposal features and using GCN layers to propagate context between proposals. Semantically similar proposals reinforce each other while background proposals are suppressed. This graph refinement boosts mAP by 2 to 4 points over direct classification of isolated proposals on both ActivityNet and THUMOS-14 benchmarks respectively.

One-stage detectors remove the explicit proposal step by directly predicting action segments at each temporal position. Methods like AFSD and ActionFormer apply a feature pyramid over temporal scales, then attach classification and regression heads at every position. Dense prediction avoids the quantization errors introduced by discretizing time into fixed-size proposals or anchor windows.

# ActionFormer: dense temporal boundary prediction\nfor pos in range(T):\n    # predict class score and start/end offsets\n    cls_score[pos], start_off[pos], end_off[pos] = head(feat[pos])\n# Soft-NMS with tIoU threshold for duplicate removal\nfinal_preds = soft_nms(cls_score, start_off, end_off, iou_thresh=0.5)

ActionFormer stacks multi-head self-attention layers along the temporal axis to capture long-range dependencies between frames. Local attention windows prevent quadratic complexity for long videos. After predicting start and end offsets at each position, Soft-NMS suppresses duplicates using tIoU, producing non-overlapping action segments ranked by confidence score for final benchmark evaluation.

****: Temporal action detection is harder than image detection because temporal boundaries are often ambiguous — actions fade in/out rather than having crisp edges. ActionFormer's dense prediction at every temporal position outperforms proposal-based methods by avoiding discretization errors.

Mean Average Precision at different tIoU thresholds is the standard evaluation metric for TAD. ActivityNet uses average mAP across tIoU 0.5 to 0.95 in 0.05 steps. THUMOS-14 reports mAP at 0.3, 0.4, 0.5, 0.6, and 0.7. Both require handling untrimmed videos: ActivityNet clips are 10 to 180 seconds while THUMOS-14 contains long sports broadcast footage up to 30 minutes per video.

Speed benchmarks measure frames-per-second throughput on a standard V100 GPU. Two-stage methods are slower because each proposal requires a separate forward pass in the classification stage. One-stage methods amortize computation across all temporal positions in a single forward pass, making them preferable for real-time deployment, though one-stage models are often larger in total parameter count.

The shift from two-stage proposal-based to one-stage transformer approaches mirrors the progression in image detection from R-CNN to DETR. ActionFormer and TriDet demonstrate that dense temporal transformers consistently outperform anchor-based methods, especially at strict tIoU thresholds of 0.7 or higher, where accurate temporal boundary prediction matters most for downstream application quality.

Multi-scale temporal feature pyramids are critical: short actions need fine temporal resolution while long actions need broader context. Future directions include video-language grounding for zero-shot TAD, efficient architectures for streaming inference on edge devices, and weakly-supervised methods that learn from video-level class labels without requiring frame-level temporal boundary annotations.
