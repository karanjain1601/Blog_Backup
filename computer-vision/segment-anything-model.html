Segment Anything Model (SAM)

Overview

Segment Anything Model (SAM), released by Meta AI in 2023, introduces a promptable segmentation foundation model. Given an image and a prompt — one or more points, a bounding box, a mask, or free-form text — SAM produces high-quality object masks in real time. Its general-purpose design enables zero-shot transfer to new domains without task-specific fine-tuning, covering medical imaging, satellite imagery, and video.

info: SAM was trained on SA-1B — 1 billion masks on 11 million images annotated with a data engine — making it the largest segmentation training effort to date.

SAM Architecture

SAM consists of three components: a heavyweight image encoder that runs once per image, a lightweight prompt encoder that processes user inputs, and a fast mask decoder that combines image and prompt embeddings to produce masks. The decoupled design is key to interactivity — the image embedding is precomputed, so each new prompt requires only a fast decoder forward pass taking under 50 ms on a GPU.

The architecture is trained with a data engine that iterates between manual annotation, semi-automatic generation, and fully automatic mask generation. This three-stage process produced SA-1B with 1.1 billion masks. The training objective combines focal loss and dice loss applied to each predicted mask, with ambiguous prompts producing up to three candidate mask outputs with associated quality scores.

Image Encoder

SAM's image encoder is a Vision Transformer ViT-H with 632 million parameters, pretrained with Masked Autoencoding. It processes images resized to 1024x1024 pixels and produces a 64x64x256 image embedding. This embedding encodes rich spatial and semantic features across the entire image at once. The heavy encoder runs only once per image, making subsequent prompt evaluations computationally efficient.

import torch
from segment_anything import sam_model_registry
from segment_anything.utils.transforms import ResizeLongestSide

sam = sam_model_registry["vit_h"](checkpoint="sam_vit_h_4b8939.pth")
sam.eval()
transform = ResizeLongestSide(1024)

# image_np: H x W x 3 uint8
img = transform.apply_image(image_np)
img_t = torch.as_tensor(img).permute(2, 0, 1).unsqueeze(0).float()

with torch.no_grad():
    embedding = sam.image_encoder(img_t)
print(embedding.shape)  # torch.Size([1, 256, 64, 64])

Window attention is used in most ViT-H layers to reduce quadratic attention cost, with global attention at evenly spaced layers to capture long-range dependencies. Relative positional embeddings are added to attention queries and keys. The final 64x64 embedding is the input to the mask decoder — each spatial position corresponds to a 16x16 pixel patch in the original 1024x1024 image.

Prompt Encoder and Mask Decoder

The prompt encoder converts sparse prompts such as points and boxes and dense prompts such as masks into prompt embeddings. Points are represented as learned positional encodings summed with foreground or background type embeddings. Bounding boxes are encoded as two corner points. Optional text prompts from CLIP are added. Dense mask prompts are downscaled and processed by a convolutional module.

import numpy as np
from segment_anything import SamPredictor, sam_model_registry

sam = sam_model_registry["vit_h"](checkpoint="sam_vit_h_4b8939.pth")
predictor = SamPredictor(sam)
predictor.set_image(image_np)    # precomputes 64x64 image embedding

coords = np.array([[500, 375]])  # (x, y) foreground point
labels = np.array([1])           # 1=foreground, 0=background

masks, scores, logits = predictor.predict(
    point_coords=coords,
    point_labels=labels,
    multimask_output=True        # returns 3 candidate masks + IoU scores
)
print(masks.shape, scores)       # (3, H, W) and [iou0, iou1, iou2]

The mask decoder is a lightweight transformer with two layers of token-to-image and image-to-token attention. It takes image embeddings, prompt embeddings, and learned output tokens as input, and produces three candidate masks with associated IoU confidence scores. Three masks handle ambiguous prompts — for a single point on a person, valid outputs include the whole person, the torso, or the face.

import numpy as np
from segment_anything import SamPredictor, sam_model_registry

sam = sam_model_registry["vit_h"](checkpoint="sam_vit_h_4b8939.pth")
predictor = SamPredictor(sam)
predictor.set_image(image_np)

# Encode bounding box in xyxy format
box = np.array([100, 200, 400, 600])  # x1, y1, x2, y2

masks, scores, _ = predictor.predict(
    point_coords=None,
    point_labels=None,
    box=box[None, :],                  # shape [1, 4]
    multimask_output=False             # box prompt -> single mask
)
print(f"Mask shape: {masks.shape}, Score: {scores[0]:.4f}")

Zero-Shot Segmentation

Zero-shot segmentation means SAM can segment object categories it never explicitly trained on. Given a point or box prompt specifying a region of interest, SAM segments the most salient object at that location without class labels. This enables rapid adaptation — point on a tumor in an MRI, click on an aerial road, annotate a retail product — all without retraining or fine-tuning the model.

import numpy as np
from segment_anything import sam_model_registry, SamAutomaticMaskGenerator

sam = sam_model_registry["vit_h"](checkpoint="sam_vit_h_4b8939.pth")
sam.to(device="cuda")

gen = SamAutomaticMaskGenerator(
    model=sam,
    points_per_side=32,
    pred_iou_thresh=0.88,
    stability_score_thresh=0.95,
    min_mask_region_area=100
)
masks = gen.generate(image_np)
print(f"{len(masks)} segments found; top score={masks[0]['predicted_iou']:.3f}")

For automatic mask generation, SAM runs a regular grid of point prompts over the image and predicts masks for each point. Duplicate masks are filtered using NMS. Stability filtering removes low-confidence masks by checking whether the predicted mask changes significantly under small threshold perturbations. The result is a comprehensive set of plausible segment masks covering the entire image automatically.

Key Takeaways

SAM demonstrates that promptable interfaces dramatically expand the utility of segmentation models. By separating heavy image encoding from lightweight prompt processing, SAM achieves interactive response times while maintaining high mask quality. This design pattern — encode once, decode many times — is now a standard approach in foundation model deployment for interactive vision tasks.

The SA-1B dataset is SAM's most significant contribution beyond the model itself. Collecting 1 billion diverse masks through a model-in-the-loop annotation engine establishes a new scale for segmentation training data. Future models trained on SA-1B benefit from SAM's broad coverage across diverse image domains including satellite, medical, and natural imagery with extremely varied object categories.

SAM 2 extends the original SAM to video by adding a memory module that propagates segmentation masks across frames. The memory encoder stores past predictions, and a memory attention mechanism conditions the mask decoder on temporal context. This enables tracking and segmenting objects through occlusions and appearance changes, expanding SAM's applicability to temporal vision tasks.

MobileSAM and FastSAM show that SAM's quality can be approximated with far fewer parameters through distillation and alternative architectures. MobileSAM replaces ViT-H with TinyViT trained via encoder distillation, achieving comparable mask quality at 10x fewer parameters. The bottleneck in SAM deployment is the image encoder, not the mask decoder — lighter encoders unlock real-time mobile applications.
