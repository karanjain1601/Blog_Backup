Confidence Intervals — Frequentist Interpretation

CIs quantify estimation uncertainty and are essential for communicating ML performance. They are also the most widely misunderstood tool in statistics.

The Correct Definition

P(L(D) ≤ θ ≤ U(D)) = 0.95 where probability is over repeated data draws.

Correct: 95% of intervals from repeated experiments contain θ.

Wrong: P(θ ∈ [L,U]) = 0.95 (that is a Bayesian credible interval). The true θ either is or is not in this specific interval — there is no probability.

CI for the Mean

σ known (z-interval): x̄ ± z_{α/2} σ/√n. For α=0.05: z_{0.025}=1.96.

σ unknown (t-interval): x̄ ± t_{n-1,α/2} · s/√n

t-distribution has heavier tails than Gaussian — accounts for uncertainty in σ. For n>100: t≈z.

CI for Proportions

Wald: p̂ ± 1.96√(p̂(1−p̂)/n) — poor coverage for extreme p or small n.

Wilson (recommended): p̃ = (h+z²/2)/(n+z²), W = z√(p̂(1−p̂)/n + z²/4n²)/(1+z²/n)

Always use Wilson for ML accuracy metrics.

Mean (σ known) x̄ ± 1.96σ/√n z-interval
Mean (σ unknown) x̄ ± t_{n-1}·s/√n t-interval
Proportion Wilson interval Near-nominal all n,p
AUC-ROC Bootstrap CI No closed form

Sample Size Determination

For mean: n ≥ (z_{α/2}·σ/δ)²

For proportion: n ≥ (z_{α/2}/δ)² · 0.25 (worst case at p=0.5)

For comparison at 80% power: n ≥ 2·(z_{α/2}+z_β)²·σ²/δ² ≈ 2·7.84·σ²/δ²

def wilson_ci(h, n, alpha=0.05):
    z = stats.norm.ppf(1 - alpha/2)
    p_hat = h / n
    center = (h + z**2/2) / (n + z**2)
    width = z * np.sqrt(p_hat*(1-p_hat)/n + z**2/(4*n**2)) / (1 + z**2/n)
    return center - width, center + width

# Sample size for margin of error
def n_needed(margin, sigma, alpha=0.05):
    z = stats.norm.ppf(1 - alpha/2)
    return int(np.ceil((z * sigma / margin)**2))

Relationship to Hypothesis Testing

θ₀ ∉ 95% CI ⟺ H₀: θ=θ₀ is rejected at α=0.05 (two-sided)

CI gives results of ALL possible tests simultaneously — far more information than a single p-value.

Bayesian Credible Interval vs Frequentist CI

CrI: P(θ ∈ [L,U] | data) = 0.95 — this IS the statement people want.

CI: [L(D), U(D)] is random; probability is about the procedure.

For large n with flat prior: CrI ≈ CI (Bernstein-von Mises theorem).

Bootstrap CIs for ML Metrics

For AUC, F1, NDCG — no closed form: 1. Resample test set B times with replacement 2. Compute metric on each bootstrap sample 3. Use percentile or BCa CI

Pair predictions from both models before bootstrapping — essential for accuracy.
