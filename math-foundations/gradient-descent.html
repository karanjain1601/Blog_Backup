Gradient Descent — Convergence Analysis and Step Size

The Update Rule

Gradient descent updates parameters along the negative gradient direction: θ ← θ − η∇L(θ), where η is the learning rate and ∇L(θ) is the gradient of the loss with respect to parameters θ. This single rule underlies virtually every modern machine learning optimizer, from plain SGD to Adam.

Geometric Interpretation

The gradient ∇L(θ) points in the direction of steepest ascent in parameter space. By moving opposite to it, gradient descent traces the path of steepest descent on the loss surface. At a minimum, the gradient is zero, so the algorithm stops updating. For a d-dimensional parameter vector, each step moves in the direction that locally decreases the loss fastest among all unit-norm directions.

Step Size Selection

The learning rate η is the most critical hyperparameter in gradient descent. If η is too large (specifically η > 2/L for an L-smooth function), updates overshoot the minimum and the algorithm diverges. If η is too small, convergence is unnecessarily slow. The optimal constant step size for L-smooth functions is η* = 1/L, which gives the fastest guaranteed convergence. In practice, η is tuned by grid search or adaptive schedulers.

import numpy as np
import matplotlib.pyplot as plt

def loss_fn(theta):
    # Ill-conditioned quadratic: condition number = 5
    return theta[0]**2 + 5 * theta[1]**2

def grad_fn(theta):
    return np.array([2*theta[0], 10*theta[1]])

def gradient_descent(lr, n_steps=80):
    theta = np.array([4.0, 3.0])
    losses = []
    for _ in range(n_steps):
        theta = theta - lr * grad_fn(theta)
        losses.append(loss_fn(theta))
    return losses

# L = 10 (largest eigenvalue of Hessian), so eta* = 1/L = 0.1
# eta > 2/L = 0.2 should diverge
lrs = [0.05, 0.09, 0.18, 0.22]
fig, ax = plt.subplots(figsize=(9, 4))
for lr in lrs:
    losses = gradient_descent(lr)
    valid = [l for l in losses if l < 1e8]
    ax.plot(valid, label=f'lr={lr}')
ax.set_xlabel('Iteration')
ax.set_ylabel('Loss (log scale)')
ax.set_title('Effect of Step Size on Convergence')
ax.legend()
ax.set_yscale('log')
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('gd_step_sizes.png', dpi=150)
plt.show()

Divergence Condition: For an L-smooth loss, gradient descent diverges when η > 2/L. The Lipschitz constant L equals the largest eigenvalue of the Hessian. For the quadratic above with Hessian diag(2, 10), L = 10, so any η > 0.2 causes divergence. Always check the Lipschitz constant or use a line search.

L-Smooth Functions and the Convergence Guarantee

A function f is L-smooth if its gradient is L-Lipschitz continuous: ‖∇f(x) − ∇f(y)‖ ≤ L‖x − y‖ for all x, y. This means the gradient cannot change too rapidly. L-smoothness implies the quadratic upper bound: f(y) ≤ f(x) + ∇f(x)ᵀ(y − x) + (L/2)‖y − x‖². For L-smooth convex functions with step size η ≤ 1/L, gradient descent is guaranteed to converge at rate O(1/T), meaning the gap f(x_T) − f ≤ L‖x_0 − x‖² / (2T).

import numpy as np
import matplotlib.pyplot as plt

# Convex quadratic f(x) = 0.5 x^2, grad f(x) = x, L = 1
# Convergence: f(x_T) - f* <= L * ||x_0 - x*||^2 / (2T)

def run_gd_1d(lr=0.5, x0=10.0, T=300):
    x = x0
    losses = []
    for _ in range(T):
        x = x - lr * x  # gradient of 0.5*x^2 is x
        losses.append(0.5 * x**2)
    return np.array(losses)

T = 300
x0, L = 10.0, 1.0
iters = np.arange(1, T + 1)
theory_bound = (L * x0**2) / (2 * iters)

losses_half = run_gd_1d(lr=0.5)
losses_best = run_gd_1d(lr=0.99)

plt.figure(figsize=(8, 4))
plt.loglog(iters, losses_half, label='GD lr=0.5')
plt.loglog(iters, losses_best, label='GD lr=0.99 (near optimal)')
plt.loglog(iters, theory_bound, 'k--', label='O(1/T) upper bound')
plt.xlabel('Iteration T')
plt.ylabel('f(x_T) - f(x*)')
plt.title('O(1/T) Convergence Rate for Convex Gradient Descent')
plt.legend()
plt.grid(True, which='both', alpha=0.3)
plt.tight_layout()
plt.savefig('convergence_rate.png', dpi=150)
plt.show()

Convergence Rates Summary

The convergence rate depends on the structure of the loss. For L-smooth convex functions, GD achieves O(1/T) sublinear convergence, meaning halving the error requires quadrupling the iterations. For μ-strongly convex functions (where the Hessian has all eigenvalues ≥ μ > 0), GD achieves linear convergence: f(x_T) − f ≤ (1 − μ/L)^T ⋅ [f(x_0) − f]. The condition number κ = L/μ determines how fast: smaller κ means faster convergence.

  • Convex + L-smooth: O(1/T) — gap halves every 2x more iterations
  • Strongly convex (μ-SC) + L-smooth: O((1-μ/L)^T) — linear convergence, κ=L/μ controls speed
  • Non-convex + L-smooth: O(1/T) to find ‖∇f(x)‖ ≤ ε (converges to stationary point, not minimum)
  • Non-smooth: slower O(1/√T) convergence even for convex, requires subgradient methods

Convex vs Non-Convex Loss Landscapes

In convex settings, any local minimum is a global minimum, and gradient descent is guaranteed to find the global optimum. In non-convex settings (all deep neural networks), the loss landscape has saddle points, local minima, and flat regions. Saddle points are especially problematic: the gradient is zero but the Hessian has both positive and negative eigenvalues. GD can get stuck near saddle points, spending exponentially long near them. In practice, noise from SGD helps escape saddle points.

import numpy as np
import matplotlib.pyplot as plt

convex_grad = lambda p: np.array([2*p[0], 2*p[1]])

# Rosenbrock: classic non-convex, narrow curved valley
rosen_grad = lambda p: np.array([
    -2*(1 - p[0]) - 400*p[0]*(p[1] - p[0]**2),
    200*(p[1] - p[0]**2)
])

def gd_path(grad_fn, x0, lr, steps):
    x = np.array(x0, dtype=float)
    path = [x.copy()]
    for _ in range(steps):
        x = x - lr * grad_fn(x)
        path.append(x.copy())
    return np.array(path)

Batch vs Mini-Batch vs Stochastic Gradient Descent

Full-batch gradient descent computes the exact gradient over all N training samples per step, which is expensive but noise-free. Stochastic GD (B=1) uses a single random sample, which is cheap but very noisy. Mini-batch GD with batch size B balances cost and variance: the gradient variance scales as σ²/B, so larger batches give lower-variance estimates. The trade-off is that large batches require more memory and may generalize worse (sharp minima) without hyperparameter tuning.

Method Memory per step Convergence Gradient noise Use case
Full-batch GD O(N) Deterministic, smooth None (σ²=0) Small datasets, convex problems
Stochastic GD (B=1) O(1) Noisy, oscillates near opt. High (σ²) Online learning, very large N
Mini-batch GD (B=32–512) O(B) Smooth with controlled noise σ²/B Deep learning standard
Full-batch + momentum O(N) Faster than GD, smooth None Convex + well-tuned LR

Gradient Flow ODE

Taking the step size η → 0 and scaling time by 1/η, gradient descent converges to the gradient flow ODE: dθ/dt = −∇L(θ). This continuous-time system is easier to analyze and is the foundation for understanding convergence proofs. Solutions to the ODE always decrease the loss monotonically. The discrete gradient descent with finite step size η approximates this ODE, with truncation errors that grow with η.

import torch
import torch.nn as nn
import torch.optim as optim
import matplotlib.pyplot as plt

torch.manual_seed(42)
X = torch.linspace(-3, 3, 200).unsqueeze(1)
y = 2.5 * X + 1.0 + 0.4 * torch.randn_like(X)

model = nn.Linear(1, 1)
optimizer = optim.SGD(model.parameters(), lr=0.05)
criterion = nn.MSELoss()

losses = []
for epoch in range(150):
    pred = model(X)
    loss = criterion(pred, y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    losses.append(loss.item())
    if epoch % 30 == 0:
        w = model.weight.item()
        b = model.bias.item()
        print(f'Epoch {epoch:3d}: loss={loss.item():.4f}, w={w:.3f}, b={b:.3f}')

plt.figure(figsize=(8, 3))
plt.plot(losses)
plt.xlabel('Epoch')
plt.ylabel('MSE Loss')
plt.title('PyTorch GD Training (Linear Regression)')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('pytorch_gd.png', dpi=150)
plt.show()

Practical Step Size Heuristic: When you don't know L, start with lr=1e-3 and increase by 3x until loss diverges. The largest stable lr is near 1/L. For transformers, lr=3e-4 with cosine decay is a reliable default. Always use warmup for Adam-based optimizers to avoid large early steps when the second moment estimate is unreliable.

  • Gradient descent update rule: θ ← θ − η∇L(θ)
  • Optimal step size for L-smooth functions: η* = 1/L
  • Convex convergence: O(1/T); Strongly convex: O((1-μ/L)^T) linear
  • Mini-batch reduces variance: Var[ġ] = σ²/B with batch size B
  • SGD noise helps escape sharp minima and improves generalization
