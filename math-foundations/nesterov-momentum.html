Nesterov Accelerated Gradient (NAG)

Lookahead Gradient Computation

Classical momentum computes the gradient at the current position θ_t, then updates. Nesterov Accelerated Gradient (NAG) instead computes the gradient at the anticipated next position θ_t − β v_t (the lookahead point), then updates: v_t = β v_{t-1} + η ∇f(θ_t − β v_{t-1}), θ_{t+1} = θ_t − v_t. The lookahead point approximates where the momentum would carry us, and evaluating the gradient there provides a correction before the overshoot happens.

import numpy as np
import matplotlib.pyplot as plt

def loss_fn(theta):
    return 0.5 * theta[0]**2 + 25 * theta[1]**2

def grad_fn(theta):
    return np.array([theta[0], 50*theta[1]])

def nag(lr, beta=0.9, n_steps=150):
    theta = np.array([3.0, 2.0])
    v = np.zeros_like(theta)
    losses, path = [], [theta.copy()]
    for _ in range(n_steps):
        # Compute gradient at lookahead position
        lookahead = theta - beta * v
        g = grad_fn(lookahead)
        v = beta * v + lr * g
        theta = theta - v
        losses.append(loss_fn(theta))
        path.append(theta.copy())
    return np.array(path), losses

def classical_momentum(lr, beta=0.9, n_steps=150):
    theta = np.array([3.0, 2.0])
    v = np.zeros_like(theta)
    losses, path = [], [theta.copy()]
    for _ in range(n_steps):
        g = grad_fn(theta)  # gradient at current position
        v = beta * v + lr * g
        theta = theta - v
        losses.append(loss_fn(theta))
        path.append(theta.copy())
    return np.array(path), losses

path_nag, losses_nag = nag(lr=0.015, beta=0.9)
path_cm, losses_cm = classical_momentum(lr=0.015, beta=0.9)
print(f'NAG final loss: {losses_nag[-1]:.6f}')
print(f'Classical momentum final loss: {losses_cm[-1]:.6f}')

Why Lookahead Corrects Overshoot

Classical momentum often overshoots the minimum because it uses the gradient at the current point before applying the momentum step. By the time the gradient correction is applied, the algorithm has already overshot. NAG evaluates the gradient after the momentum step (at the anticipated position), so the gradient correction is applied at a better location. If the momentum would carry the iterate past the minimum, the lookahead gradient points back toward it, dampening the overshoot before it occurs.

Optimal Convergence Rate: NAG achieves the optimal O(1/T²) convergence rate for smooth convex functions, matching the lower bound proved by Nesterov (1983). This means to reach error ε, NAG requires O(1/√ε) iterations while GD requires O(1/ε) iterations — a quadratic speedup in the number of gradient evaluations. For strongly convex functions, both achieve linear convergence, but NAG has better constants.

O(1/T²) Convergence

For an L-smooth convex function with NAG: f(x_T) − f ≤ 2L‖x_0 − x‖² / (T+1)². Compared to O(1/T) for gradient descent, this is a dramatic improvement. The O(1/T²) rate is provably optimal for first-order methods on smooth convex functions — no deterministic first-order algorithm can do better without additional structure. The convergence proof uses a carefully constructed potential (Lyapunov) function that decreases monotonically with a specific rate.

import numpy as np
import matplotlib.pyplot as plt

def run_optimizer(grad_fn, loss_fn, method='gd', lr=0.5, beta=0.9, T=200):
    x = np.array([10.0])
    v = np.zeros_like(x)
    losses = []
    for t in range(T):
        if method == 'gd':
            x = x - lr * grad_fn(x)
        elif method == 'momentum':
            v = beta * v + lr * grad_fn(x)
            x = x - v
        elif method == 'nag':
            lookahead = x - beta * v
            v = beta * v + lr * grad_fn(lookahead)
            x = x - v
        losses.append(float(loss_fn(x)))
    return np.array(losses)

# Simple 1D convex: f(x) = 0.5*x^2, L = 1
grad_1d = lambda x: x
loss_1d = lambda x: 0.5 * x**2
T = 200
iters = np.arange(1, T + 1)
loss_gd = run_optimizer(grad_1d, loss_1d, 'gd', lr=0.5, T=T)
loss_cm = run_optimizer(grad_1d, loss_1d, 'momentum', lr=0.1, beta=0.9, T=T)
loss_nag = run_optimizer(grad_1d, loss_1d, 'nag', lr=0.1, beta=0.9, T=T)

plt.figure(figsize=(9, 4))
plt.loglog(iters, loss_gd, label='GD: O(1/T)')
plt.loglog(iters, loss_cm, label='Classical Momentum')
plt.loglog(iters, loss_nag, label='NAG: O(1/T^2)')
plt.loglog(iters, 50/iters, 'k--', label='O(1/T) reference')

The Substitution Trick for Efficient Implementation

The naive NAG implementation requires computing the gradient at two points: the current θ_t and the lookahead θ_t − β v_t. The substitution trick avoids this by working in transformed variables. Let φ_t = θ_t − β v_t (the lookahead position). Then the NAG update in terms of φ becomes: v_t = β v_{t-1} + η ∇f(φ_t) and φ_{t+1} = φ_t − η(1+β) ∇f(φ_t) + β² v_{t-1}. This lets you compute the gradient only once per step.

import numpy as np
import matplotlib.pyplot as plt

def loss_fn(theta):
    return theta[0]**2 + 25 * theta[1]**2

def grad_fn(theta):
    return np.array([2*theta[0], 50*theta[1]])

def nag_substitution(lr, beta=0.9, n_steps=200):
    # Work in phi = theta - beta*v (lookahead variable)
    phi = np.array([3.0, 2.0])
    v = np.zeros(2)
    losses, path = [], []
    for _ in range(n_steps):
        g = grad_fn(phi)     # gradient at lookahead (only one gradient call)
        v_new = beta * v + lr * g
        phi = phi - lr * (1 + beta) * g + beta**2 * v  # update lookahead
        v = v_new
        # recover theta = phi + beta*v
        theta = phi + beta * v
        losses.append(loss_fn(theta))
        path.append(theta.copy())
    return np.array(path), losses

path_nag, losses_nag = nag_substitution(lr=0.018, beta=0.9)
X, Y = np.meshgrid(np.linspace(-3.5, 3.5, 200), np.linspace(-2.5, 2.5, 200))
Z = X**2 + 25*Y**2
plt.figure(figsize=(7, 5))
plt.contourf(X, Y, np.clip(Z, 0, 50), levels=20, cmap='viridis', alpha=0.7)
path = np.array(path_nag)
plt.plot(path[:,0], path[:,1], 'r.-', markersize=4, linewidth=1.5, label='NAG path')
plt.title('NAG on Ill-Conditioned Quadratic (Substitution Trick)')
plt.xlabel('x1'); plt.ylabel('x2'); plt.legend()
plt.savefig('nag_trajectory.png', dpi=150)
plt.show()

Convergence Rate Comparison

The table below compares convergence rates across first-order methods. GD achieves O(1/T) for smooth convex functions; NAG achieves the optimal O(1/T²). For strongly convex functions, both GD and NAG achieve linear convergence with rate (1 − μ/L) and (1 − √(μ/L)) respectively. Classical heavy ball with the optimal parameters also achieves linear convergence with rate (1 − √(μ/L)) on quadratics, but can be non-monotone and diverge on general strongly convex functions.

Method Smooth convex Strongly convex rate Notes
Gradient Descent O(1/T) (1 - μ/L)^T Simple, stable; η = 1/L
Classical Momentum (Heavy Ball) O(1/T) in best case (1 - √(μ/L))^T on quadratics Can diverge on non-quadratic SC
Nesterov AGD O(1/T²) — optimal (1 - √(μ/L))^T guaranteed Optimal for smooth convex; stable
Conjugate Gradient Exact in n steps (quadratic) O(√κ) iters (quadratic) Best for dense quadratics, no DL use

PyTorch Implementation

PyTorch's SGD optimizer supports Nesterov momentum via the nesterov=True flag. Internally, PyTorch implements NAG using the substitution trick. The interface is identical to SGD with momentum — the only change is the flag. In practice, Nesterov momentum often gives slightly better convergence on smooth convex problems, but the difference is less pronounced in deep learning where the loss is non-convex.

import torch
import torch.nn as nn
import torch.optim as optim
import matplotlib.pyplot as plt

torch.manual_seed(42)
X = torch.randn(300, 15)
y = X @ torch.ones(15) + 0.2 * torch.randn(300)
y = y.unsqueeze(1)

def train(optimizer_fn, epochs=100):
    model = nn.Linear(15, 1)
    opt = optimizer_fn(model.parameters())
    crit = nn.MSELoss()
    losses = []
    for _ in range(epochs):
        pred = model(X)
        loss = crit(pred, y)
        opt.zero_grad()
        loss.backward()
        opt.step()
        losses.append(loss.item())
    return losses

configs = [
    ('SGD', lambda p: optim.SGD(p, lr=0.01)),
    ('SGD + Momentum', lambda p: optim.SGD(p, lr=0.01, momentum=0.9)),
    ('SGD + Nesterov', lambda p: optim.SGD(p, lr=0.01, momentum=0.9, nesterov=True)),
]
plt.figure(figsize=(8, 4))
for name, opt_fn in configs:
    plt.plot(train(opt_fn), label=name)
plt.xlabel('Epoch'); plt.ylabel('MSE Loss')
plt.title('SGD vs Momentum vs Nesterov (PyTorch)')
plt.legend(); plt.yscale('log'); plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('nag_pytorch.png', dpi=150)
plt.show()

Potential Function Proof Sketch

The O(1/T²) rate is proved via a Lyapunov (energy) function E_t = (T+1)²[f(x_t) − f] + 2L‖x_t − x‖² (roughly). One shows that E_t is non-increasing (the algorithm is conservative in energy) and that the first term dominates, giving f(x_T) − f* = O(E_0 / T²). The key identity used is: f(x) ≤ f(y) + ∇f(y)ᵀ(x − y) + (L/2)‖x − y‖² (L-smoothness), applied at specific points in the NAG recursion.

  • NAG computes gradient at lookahead position θ − βv, not at current θ
  • Achieves optimal O(1/T²) for smooth convex — quadratic speedup over GD
  • Linear convergence for strongly convex: rate 1 − √(μ/L) vs 1 − μ/L for GD
  • Substitution trick: compute gradient only once per step (not twice)
  • PyTorch: optim.SGD(..., momentum=0.9, nesterov=True)

When to Use NAG: Use Nesterov momentum (SGD + nesterov=True) when training on smooth, near-convex problems such as linear/logistic regression or when fine-tuning with a small learning rate. For deep networks with Adam, NAG provides less benefit since Adam already adapts step sizes. In practice, SGD with Nesterov momentum and cosine LR scheduling remains competitive with Adam on image classification tasks.
