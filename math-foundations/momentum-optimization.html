Momentum and Exponential Moving Averages

The Heavy Ball Method

The heavy ball (Polyak momentum) method accumulates a velocity vector v_t that acts like physical momentum: v_t = β v_{t-1} + η g_t, then θ ← θ − v_t. The momentum coefficient β (typically 0.9–0.99) controls how much of the past velocity is retained. With β=0.9, the velocity is a decaying sum of past gradients, with more recent gradients receiving higher weight.

import numpy as np
import matplotlib.pyplot as plt

def loss_fn(theta):
    # Ill-conditioned quadratic: kappa = L/mu = 100/1 = 100
    return 0.5 * theta[0]**2 + 50 * theta[1]**2

def grad_fn(theta):
    return np.array([theta[0], 100*theta[1]])

def sgd_with_momentum(lr, beta=0.9, n_steps=200):
    theta = np.array([3.0, 2.0])
    v = np.zeros_like(theta)
    losses, path = [], [theta.copy()]
    for _ in range(n_steps):
        g = grad_fn(theta)
        v = beta * v + lr * g
        theta = theta - v
        losses.append(loss_fn(theta))
        path.append(theta.copy())
    return np.array(path), losses

def plain_gd(lr, n_steps=200):
    theta = np.array([3.0, 2.0])
    losses, path = [], [theta.copy()]
    for _ in range(n_steps):
        theta = theta - lr * grad_fn(theta)
        losses.append(loss_fn(theta))
        path.append(theta.copy())
    return np.array(path), losses

path_m, losses_m = sgd_with_momentum(lr=0.01, beta=0.9)
path_gd, losses_gd = plain_gd(lr=0.01)

fig, axes = plt.subplots(1, 2, figsize=(12, 4))
axes[0].semilogy(losses_gd, label='Plain GD lr=0.01')
axes[0].semilogy(losses_m, label='Momentum beta=0.9 lr=0.01')
axes[0].set_xlabel('Iteration'); axes[0].set_ylabel('Loss')
axes[0].set_title('Momentum vs GD on Ill-Conditioned Quadratic')
axes[0].legend(); axes[0].grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('momentum_comparison.png', dpi=150)
plt.show()

Geometric Series Analysis

The velocity after T steps is v_T = η Σ_{k=0}^{T-1} β^k g_{T-k}, a geometric sum of past gradients. If all gradients point in the same direction (g_t = g for all t), the sum telescopes: v_T → ηg / (1-β) as T → ∞. This is the effective learning rate amplification: momentum multiplies the effective step size by 1/(1-β). With β=0.9, the effective lr is 10× the nominal lr in consistent gradient directions.

Effective Learning Rate: With momentum β, the effective learning rate in a consistent gradient direction is η_eff = η / (1-β). At β=0.9: η_eff = 10η. At β=0.99: η_eff = 100η. This means you should reduce the nominal learning rate when adding momentum — or increase β gradually during training (as in LAMB and some warmup schedules).

Oscillation Damping in High-Curvature Directions

In directions of high curvature (large Hessian eigenvalue), gradients oscillate — alternating in sign each step. Momentum partially cancels these oscillations: when the gradient flips sign, the velocity partially cancels the new gradient, reducing the effective step size in that direction. This automatic damping makes momentum particularly effective on ill-conditioned problems where plain GD zigzags toward the minimum.

import numpy as np
import matplotlib.pyplot as plt

def run_optimizer(grad_fn, lr, beta=0.0, n_steps=150):
    theta = np.array([3.0, 2.0])
    v = np.zeros_like(theta)
    path = [theta.copy()]
    for _ in range(n_steps):
        g = grad_fn(theta)
        v = beta * v + lr * g
        theta = theta - v
        path.append(theta.copy())
    return np.array(path)

# Highly ill-conditioned quadratic (kappa=100)
grad_fn = lambda p: np.array([p[0], 100*p[1]])

X, Y = np.meshgrid(np.linspace(-3.5, 3.5, 200), np.linspace(-2.5, 2.5, 200))

EMA as a Low-Pass Filter

An exponential moving average (EMA) of a sequence x_t is defined as s_t = β s_{t-1} + (1-β) x_t. This is a first-order IIR low-pass filter: it attenuates high-frequency oscillations and passes low-frequency trends. The effective memory window is 1/(1-β) steps. In optimization, momentum uses a variant without the (1-β) factor: v_t = β v_{t-1} + g_t (unnormalized EMA). Gradient tracking statistics (Adam's m_t) use the normalized EMA.

import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)
t = np.arange(200)
# Noisy signal: slow trend + noise
signal = np.sin(2 * np.pi * t / 100) + 0.5 * np.random.randn(200)

def ema(signal, beta):
    s = np.zeros_like(signal)
    s[0] = signal[0]
    for i in range(1, len(signal)):
        s[i] = beta * s[i-1] + (1 - beta) * signal[i]
    return s

betas = [0.5, 0.9, 0.99]
plt.figure(figsize=(10, 4))
plt.plot(signal, 'gray', alpha=0.4, label='Noisy signal')
for beta in betas:
    window = int(1 / (1 - beta))
    smoothed = ema(signal, beta)
    plt.plot(smoothed, linewidth=2, label=f'EMA beta={beta} (window~{window})')
plt.xlabel('Time step')
plt.ylabel('Value')
plt.title('EMA as Low-Pass Filter: Different beta Values')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('ema_lowpass.png', dpi=150)
plt.show()

# Print effective window sizes
for b in [0.5, 0.9, 0.95, 0.99, 0.999]:
    print(f'beta={b}: effective window = {1/(1-b):.0f} steps')

Momentum Beta Values and Window Size

The effective window size 1/(1-β) quantifies how many recent gradients influence the current velocity. With β=0.9 (the PyTorch SGD default), the last ~10 gradients are meaningfully weighted. With β=0.99, the window expands to ~100 steps. Higher β gives smoother updates but makes the optimizer slower to adapt to changing gradient directions. For Adam, β₂=0.999 (the second moment) needs a large window to accurately estimate gradient variance.

β value Effective window (1/(1-β)) Effective LR multiplier Typical use
0.5 2 2× Rarely used; very responsive
0.9 10 10× SGD momentum default; standard for vision
0.95 20 20× Smoother updates; useful for noisy gradients
0.99 100 100× Very smooth; SWA weight averaging
0.999 1000 1000× Adam β₂ for second moment estimation

Stochastic Weight Averaging (SWA)

SWA (Izmailov et al., 2018) averages model weights over the last portion of training rather than taking the final weights. This finds flatter, wider minima in the loss landscape that generalize better. The averaged weights often outperform the final checkpoint by 1–2% on accuracy. SWA uses a running average (EMA with β close to 1, or uniform averaging) of weights. PyTorch provides torch.optim.swa_utils for easy implementation.

import torch
import torch.nn as nn
import torch.optim as optim
from torch.optim.swa_utils import AveragedModel, SWALR

torch.manual_seed(42)
X = torch.randn(200, 10)
y = (X[:, 0] + X[:, 1] > 0).float().unsqueeze(1)

base_model = nn.Sequential(nn.Linear(10, 32), nn.ReLU(), nn.Linear(32, 1), nn.Sigmoid())
swa_model = AveragedModel(base_model)

optimizer = optim.SGD(base_model.parameters(), lr=0.05, momentum=0.9)
crit = nn.BCELoss()
dataset = torch.utils.data.TensorDataset(X, y)
loader = torch.utils.data.DataLoader(dataset, batch_size=32, shuffle=True)

# Phase 1: regular training
for epoch in range(40):
    for xb, yb in loader:
        optimizer.zero_grad()
        crit(base_model(xb), yb).backward()
        optimizer.step()

# Phase 2: SWA averaging with cyclical LR
swa_scheduler = SWALR(optimizer, swa_lr=0.01, anneal_epochs=5)
for epoch in range(20):
    for xb, yb in loader:
        optimizer.zero_grad()
        crit(base_model(xb), yb).backward()
        optimizer.step()
    swa_model.update_parameters(base_model)
    swa_scheduler.step()

# Update batch norm statistics for swa_model
torch.optim.swa_utils.update_bn(loader, swa_model)
print('SWA training complete. swa_model contains averaged weights.')

EMA in Practice: RL Target Networks and BYOL

EMA of model weights appears throughout deep learning beyond optimization. In DQN, a target network is an EMA copy of the online network, updated as θ_target ← β θ_target + (1-β) θ_online (with β≈0.995). The target network provides stable regression targets, preventing divergence from the moving-target problem. BYOL (self-supervised learning) uses the same idea: the momentum encoder provides stable embeddings that the online network learns to match.

  • Heavy ball: v_t = β v_{t-1} + η g_t, θ ← θ − v_t
  • Effective LR multiplier: 1/(1-β) in consistent gradient directions
  • EMA window size: 1/(1-β) steps; beta=0.9 → window=10
  • SWA averages weights over late training for flatter minima
  • EMA target networks stabilize training in DQN, BYOL, Barlow Twins

Tuning Momentum: Start with β=0.9 for SGD. If training oscillates, reduce β to 0.85. If loss plateaus early, try increasing β to 0.95. When switching from SGD to Adam, β₁=0.9 is usually fine; the second moment β₂=0.999 should stay fixed in most cases. For SWA, begin averaging in the last 25–40% of training steps.
