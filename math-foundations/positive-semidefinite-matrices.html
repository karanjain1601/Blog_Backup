Positive Semidefinite Matrices

Positive semidefinite (PSD) matrices are the 'positive' matrices of linear algebra — they generalize the notion of a non-negative scalar to the matrix world. PSD matrices arise naturally as covariance matrices, kernel matrices, and Hessians of convex functions. Understanding PSD structure is essential for convex optimization, kernel methods, Gaussian processes, and numerical stability analysis.

Definition: The Quadratic Form Test

A symmetric matrix A ∈ ℝⁿˣⁿ is positive semidefinite (PSD) if for every vector x ∈ ℝⁿ:

xᵀAx ≥ 0

The expression xᵀAx is the quadratic form associated with A. It is a scalar that measures how A 'weighs' the vector x against itself. A is positive definite (PD) if xᵀAx > 0 for all x ≠ 0 (strictly positive). The difference: PSD allows some directions where A collapses the vector to zero (rank-deficient), while PD guarantees full rank and invertibility.

import numpy as np

def check_psd(A, tol=1e-10):
    """Check positive semidefiniteness via eigenvalues."""
    eigenvalues = np.linalg.eigvalsh(A)  # eigvalsh for symmetric
    return np.all(eigenvalues >= -tol)

# PSD example: outer product
v = np.array([1., 2., 3.])
A_psd = np.outer(v, v)   # vvᵀ: rank-1, PSD
print('Outer product PSD?', check_psd(A_psd))   # True

# PD example: A^T A + lambda I
np.random.seed(0)
X = np.random.randn(5, 5)
A_pd = X.T @ X + 0.1 * np.eye(5)  # strictly PD
print('A_pd PD?', check_psd(A_pd))    # True
print('Min eigenvalue:', np.min(np.linalg.eigvalsh(A_pd)))  # > 0

# Random symmetric matrix: NOT necessarily PSD
A_indef = X + X.T  # symmetric but indefinite
print('Random symmetric PSD?', check_psd(A_indef))  # likely False

Equivalent Characterizations of PSD

A symmetric matrix A is PSD if and only if any of the following equivalent conditions holds:

  1. All eigenvalues are non-negative: λᵢ ≥ 0 for all i (from spectral theorem)
  2. Gram matrix form: There exists a matrix B such that A = BᵀB (Cholesky factor)
  3. All leading principal minors are non-negative: det of top-left k×k submatrices ≥ 0
  4. The quadratic form is non-negative: xᵀAx ≥ 0 for all x
  5. All diagonal entries are non-negative (necessary but not sufficient alone)

For PD (strictly positive), all eigenvalues are strictly positive, and A = BᵀB where B is invertible.

Cholesky Decomposition

Every positive definite matrix A can be uniquely factored as A = LLᵀ where L is a lower triangular matrix with positive diagonal entries — the Cholesky decomposition. It is the 'square root' of a positive definite matrix.

Cholesky is twice as fast as general LU decomposition and numerically stable. Key uses: - Solving PD linear systems: Solve Lz = b (forward substitution), then Lᵀx = z (back substitution) - Multivariate Gaussian sampling: To sample x ~ N(μ, Σ), compute L = chol(Σ), then x = μ + Lz where z ~ N(0, I) - Testing PD: Cholesky succeeds iff the matrix is PD — a practical PD test

import numpy as np

# PD matrix
A = np.array([[4., 2., 0.],
              [2., 3., 1.],
              [0., 1., 2.]])

# Cholesky: A = L L^T
L = np.linalg.cholesky(A)
print('L (lower triangular):\n', L)
print('L L^T error:', np.linalg.norm(A - L @ L.T))  # ~1e-16

# Solve Ax = b via Cholesky
b = np.array([1., 2., 3.])
# Forward substitution: L z = b
z = np.linalg.solve(L, b)
# Back substitution: L^T x = z
x = np.linalg.solve(L.T, z)
print('Solution:', x)
print('Verify Ax = b:', np.allclose(A @ x, b))

# Sample from multivariate Gaussian
np.random.seed(42)
Sigma = A   # use A as covariance
mu = np.zeros(3)
L_s = np.linalg.cholesky(Sigma)
samples = mu + L_s @ np.random.randn(3, 1000)
print('Sample covariance (should match Sigma):\n', np.round(samples @ samples.T / 1000, 2))

PSD Matrices as Covariance Matrices

Every covariance matrix is PSD. For data matrix X (n×d, centered), the sample covariance C = (1/n)XᵀX is automatically PSD because for any v: vᵀCv = (1/n)||Xv||₂² ≥ 0.

The eigenvalues of C are the variances in the directions of the eigenvectors (principal components). Zero eigenvalues indicate directions in feature space with zero variance — the data lies on a lower-dimensional hyperplane. This is why PCA requires only eigenvectors with positive eigenvalues.

For a Gaussian distribution N(μ, Σ), the covariance matrix Σ must be PSD (PD for non-degenerate distributions). The precision matrix Σ⁻¹ (used in Mahalanobis distance) is also PD when Σ is PD.

Kernels and Mercer's Theorem

A kernel function K(x, z) defines pairwise similarities between inputs. The kernel matrix (or Gram matrix) K with entries Kᵢⱼ = K(xᵢ, xⱼ) must be PSD for the kernel to be valid.

Mercer's theorem states that a symmetric kernel K(x,z) corresponds to an inner product in some feature space φ: K(x,z) = ⟨φ(x), φ(z)⟩ if and only if the kernel matrix is PSD for all finite sets of points. This is why kernels can implicitly compute dot products in infinite-dimensional spaces (the 'kernel trick') — the PSD requirement guarantees geometric validity.

Common kernels: Linear K(x,z)=xᵀz, RBF K(x,z)=exp(-||x-z||²/2σ²), Polynomial K(x,z)=(xᵀz+c)ᵈ — all provably PSD.

import numpy as np

def rbf_kernel(X, sigma=1.0):
    """Radial Basis Function (Gaussian) kernel matrix."""
    # ||xi - xj||^2 = ||xi||^2 + ||xj||^2 - 2 xi^T xj
    sq_dists = (np.sum(X**2, axis=1, keepdims=True) +
                np.sum(X**2, axis=1) -
                2 * X @ X.T)
    return np.exp(-sq_dists / (2 * sigma**2))

np.random.seed(0)
X = np.random.randn(10, 3)
K = rbf_kernel(X, sigma=1.0)

# Verify PSD
eigenvalues = np.linalg.eigvalsh(K)
print('Min eigenvalue:', eigenvalues.min())  # should be >= 0
print('Is PSD:', eigenvalues.min() >= -1e-10)
print('K is symmetric:', np.allclose(K, K.T))

The PSD Cone and Convexity

The set of all n×n PSD matrices forms a convex cone called the PSD cone, denoted S⁺ₙ. A cone is a set closed under positive scalar multiplication (λA ∈ S⁺ₙ for λ>0); convex means the average of two PSD matrices is PSD.

The PSD cone is the feasible set in Semidefinite Programming (SDP), a powerful generalization of linear programming. Many ML problems (kernel learning, robust PCA, MAXCUT relaxations, covariance estimation with PSD constraints) can be cast as SDPs.

For optimization, a function f(x) is convex if its Hessian ∇²f(x) is PSD everywhere. The quadratic form viewpoint: f is convex iff vᵀ∇²f(x)v ≥ 0 for all directions v — curvature is non-negative in every direction. PD Hessian implies strict convexity (unique minimum).

Hessian PSD and Convergence of Gradient Descent

The loss function in ML is convex (and thus has no local minima other than global) if and only if its Hessian is PSD everywhere. The condition number κ = λ_max / λ_min of the Hessian determines how fast gradient descent converges:

  • Large κ (ill-conditioned): loss surface is elongated; gradient descent oscillates and converges slowly. The convergence rate per step is (κ-1)/(κ+1).
  • Small κ ≈ 1 (well-conditioned): loss surface is spherical; gradient descent converges in O(log(1/ε)) steps.

Preconditioning (transforming coordinates to equalize eigenvalues) is the idea behind adaptive optimizers (AdaGrad, Adam): they approximate the Hessian diagonal to rescale gradients, effectively reducing the condition number.

[WARNING] Numerical Issues with Near-PSD Matrices

Due to floating-point errors, covariance matrices computed from data can have small negative eigenvalues (e.g., -1e-12) even though they should be PSD. Before Cholesky decomposition, add a small jitter: A_stable = A + 1e-6 * np.eye(n). This is standard practice in Gaussian Process implementations. Libraries like GPyTorch handle this automatically.
