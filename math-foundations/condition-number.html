Condition Number and Numerical Stability

The condition number measures how much a small input change amplifies into an output change. A condition number of $10^k$ means approximately $k$ decimal digits of output precision are lost per digit of input error.

Definition

$$\kappa(A) = |A|2 \cdot |A^{-1}|_2 = \frac{\sigma$$}}{\sigma_{\min}

For symmetric positive definite matrices: $\kappa = \lambda_{\max}/\lambda_{\min}$.

For scalar $f$: $\kappa(f,x) = |x\,f'(x)| / |f(x)|$ — the relative condition number.

Interpretation for Linear Systems

For $Ax = b$:

$$\frac{|\delta x|}{|x|} \leq \kappa(A) \cdot \frac{|\delta b|}{|b|}$$

In fp32 ($\varepsilon \approx 10^{-7}$): if $\kappa(A) = 10^7$, the solution has essentially zero correct significant digits.

Condition Number of the Loss Hessian

$H = \partial^2 L / \partial\theta^2$. Its condition number $\kappa(H) = \lambda_{\max}/\lambda_{\min}$ determines:

  1. Convergence rate of GD: $|x_t - x^| \leq \left(\frac{\kappa-1}{\kappa+1}\right)^t |x_0 - x^|$ — requires $O(\kappa\log(1/\varepsilon))$ steps.
  2. Optimal learning rate: $\alpha^* = 2/(\lambda_{\max}+\lambda_{\min})$; above $2/\lambda_{\max}$ causes divergence.
  3. Generalisation: high-$\kappa$ Hessians (sharp minima) often generalise worse.
import numpy as np

# Condition number of a matrix
A = np.array([[1.0, 0.0],[0.0, 1000.0]])
svs = np.linalg.svd(A, compute_uv=False)
print(f'kappa = {svs.max()/svs.min():.1f}')   # 1000.0

# Effect of feature scaling on condition number
np.random.seed(0)
X = np.random.randn(1000, 10)
X[:,0] *= 100                                  # one high-variance feature
cov = np.cov(X.T)
print(f'Unscaled kappa: {np.linalg.cond(cov):.0f}')    # ~10000

X_white = (X - X.mean(0)) / X.std(0)
cov_w = np.cov(X_white.T)
print(f'Whitened kappa: {np.linalg.cond(cov_w):.2f}')  # ~1.0

Convergence Rate and Condition Number

Method Convergence Steps to $\varepsilon$ accuracy
Gradient descent $O((\kappa-1)/(\kappa+1))^t$ $O(\kappa\log(1/\varepsilon))$
Conjugate gradient Superlinear $O(\sqrt{\kappa}\log(1/\varepsilon))$
Newton's method Quadratic $O(\log\log(1/\varepsilon))$
Adam (diagonal precond.) Effective $\kappa \to 1$ Robust to ill-conditioning

Preconditioning and Second-Order Optimisation

Preconditioned GD: $\theta_{t+1} = \theta_t - P^{-1}\nabla L(\theta_t)$

  • $P = H$: Newton's method, $\kappa_{\text{eff}}=1$, quadratic convergence
  • $P = \text{diag}(H)$: Jacobi, cheap but partial
  • $P = \text{diag}(\mathbb{E}[g^2])$: Adam/RMSProp — diagonal Hessian approximation

Adam's $m_t/\sqrt{v_t}$ update approximates the diagonal of $H^{-1}$, giving Adam its preconditioning property.

Batch Normalisation Reduces Condition Number

Without BN: effective Hessian condition number grows exponentially with depth (product of activation variance ratios). With BN: each layer's output is independently normalised → Hessian condition number $\approx 1$ → learning rates 10–100× larger are stable.

Scenario $\kappa$ Convergence Mitigation
Well-conditioned ~1–10 Fast None needed
Moderately ill-cond. $10^2$–$10^4$ Slow Adam, lr schedule
Ill-conditioned $10^6$–$10^8$ Very slow / diverges BN, LN, preconditioning
Extremely ill-cond. $10^{10}+$ Numerically unstable Normalise inputs/architecture

TIP: Estimating Condition Number Efficiently For large networks, use Lanczos algorithm with Hessian-vector products (Pearlmutter trick) to estimate $\lambda_{\max}$ and $\lambda_{\min}$ without forming $H$. Gradient variance ratios and BatchNorm statistics provide cheaper proxies.

WARNING: High Condition Number Signals Sharp Minima High $\kappa(H)$ at a minimum (flat in some directions, sharp in others) predicts poor generalisation. SAM (Sharpness-Aware Minimisation, Foret 2021) explicitly seeks low-$\kappa$ minima, adding a perturbation step to find uniformly flat regions.
