Conjugate Priors and Closed-Form Posteriors

Conjugate priors enable closed-form Bayesian inference — as cheap as MLE, with principled uncertainty quantification.

Definition

Prior p(θ|ψ) is conjugate to likelihood p(x|θ) if the posterior p(θ|x) is in the same parametric family with updated parameters.

For exponential family likelihood p(x|η) = h(x)exp(ηᵀT(x)−A(η)): Conjugate prior: p(η|χ,ν) ∝ exp(ηᵀχ − νA(η)) Update: χ'=χ+ΣT(xᵢ), ν'=ν+n

Beta-Bernoulli

Prior: θ~Beta(α,β). After h heads, t tails:

Posterior: Beta(α+h, β+t) — update rules: α'=α+h, β'=β+t

Posterior mean = (α+h)/(α+β+n) — precision-weighted interpolation between prior and MLE.

Hyperparameters α,β are pseudo-counts: equivalent prior observations.

Dirichlet-Categorical

Prior: π~Dirichlet(α₁,…,αK). After observing nₖ instances of class k:

Posterior: Dirichlet(α₁+n₁, …, αK+nK) — update αₖ'=αₖ+nₖ

Posterior mean: E[πₖ|data] = (αₖ+nₖ)/(Σαⱼ+n). With α=1 (Laplace smoothing): P(wⱼ|c) = (count+1)/(N+V).

Gaussian-Gaussian (known variance)

Prior: μ~N(μ₀,σ₀²). Posterior after n observations:

1/σₙ² = 1/σ₀² + n/σ² (precision adds) μₙ = σₙ²(μ₀/σ₀² + nx̄/σ²) (precision-weighted average)

Flat prior (σ₀²→∞): μₙ→x̄ (MLE). Large n: data dominates.

Likelihood Prior Posterior Application
Bernoulli(θ) Beta(α,β) Beta(α+h,β+t) A/B testing
Categorical(π) Dirichlet(α) Dirichlet(α+n) Naive Bayes, LDA
Gaussian(μ,σ²) Gaussian(μ₀,σ₀²) Gaussian(μₙ,σₙ²) Kalman filter
Poisson(λ) Gamma(α,β) Gamma(α+Σx,β+n) Count data

def beta_bernoulli_update(alpha, beta, observations):
    h, t = sum(observations), len(observations) - sum(observations)
    return alpha + h, beta + t  # posterior parameters

Conjugacy in LDA

LDA uses Dirichlet-Categorical conjugacy for both topic-document and word-topic distributions.

Full conditional for Gibbs: p(z_{d,n}=k|rest) ∝ (n_{d,k}+α) · (n_{k,w}+β) / (n_{k,·}+Vβ)

Computable in O(K) — no matrix inversions. Scales to millions of documents via collapsed Gibbs or variational inference.

Why Conjugacy Works

  • Sufficient statistics: update uses only T(xᵢ) — fixed-dimension summary
  • Online learning: each new observation produces a valid new prior
  • Rao-Blackwellisation: integrate out conjugate variables analytically in hybrid models
