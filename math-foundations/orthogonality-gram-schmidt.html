Orthogonality and the Gram-Schmidt Process

Orthogonality — the geometric concept of perpendicularity generalized to any number of dimensions — is one of the most useful structural properties in linear algebra. Orthogonal bases make computation simple, projections onto orthogonal subspaces are stable, and orthogonal matrices preserve geometry. The Gram-Schmidt process is the algorithm that takes any basis and makes it orthogonal — the foundation of QR decomposition and numerous numerical methods.

Orthogonal and Orthonormal Vectors

Two vectors u and v are orthogonal if their dot product is zero: u · v = 0. Geometrically, they are perpendicular. A set of vectors is orthogonal if every pair is mutually orthogonal. They are orthonormal if additionally each vector has unit length: ||vᵢ|| = 1 for all i.

An orthonormal set {q₁, ..., qₖ} satisfies: qᵢ · qⱼ = δᵢⱼ (Kronecker delta: 1 if i=j, 0 otherwise). An orthogonal matrix Q has orthonormal columns and satisfies QᵀQ = I (and QQᵀ = I when Q is square), meaning Qᵀ = Q⁻¹. Orthogonal matrices are the rotation/reflection matrices — they preserve lengths and angles.

import numpy as np

# Check orthogonality
u = np.array([1., 0., 0.])
v = np.array([0., 1., 0.])
w = np.array([0., 0., 1.])
print('u.v:', np.dot(u, v))  # 0 -- orthogonal
print('u.w:', np.dot(u, w))  # 0

# Rotation matrix is orthogonal
theta = np.pi / 4
Q = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])
print('QᵀQ:\n', Q.T @ Q)            # identity (to machine precision)
print('det(Q):', np.linalg.det(Q))   # 1.0 (rotation, not reflection)

# Orthogonal matrices preserve norms
v2d = np.array([3., 4.])
print('||v||:', np.linalg.norm(v2d))             # 5.0
print('||Qv||:', np.linalg.norm(Q @ v2d))        # 5.0 -- preserved!

Projection onto a Subspace

The orthogonal projection of a vector b onto the subspace spanned by columns of matrix A is the vector in the subspace closest to b (in L2 norm). The projection is:

p = A(AᵀA)⁻¹Aᵀb

The projection matrix P = A(AᵀA)⁻¹Aᵀ is idempotent (P² = P) and symmetric (P = Pᵀ). The residual b - Pb is orthogonal to every column of A: Aᵀ(b - Pb) = 0.

When A has orthonormal columns (AᵀA = I), projection simplifies to p = AAᵀb. The projection of b onto a single unit vector q is (qᵀb)q — scale the unit vector by the scalar dot product.

Least Squares as Projection

The least-squares solution to an overdetermined system Ax ≈ b (more equations than unknowns) is exactly the orthogonal projection of b onto the column space of A. The solution x = (AᵀA)⁻¹Aᵀb (assuming full column rank) satisfies the normal equations: Aᵀ(Ax - b) = 0**.

The geometric interpretation is beautiful: Ax is the point in the column space of A closest to b. The residual r = b - Ax is orthogonal to every column of A** — this is why the equations are called 'normal' (from the Latin for perpendicular). This gives least squares a clean geometric meaning: find the projection of b onto the column space.

import numpy as np

# Overdetermined system: 5 equations, 2 unknowns
A = np.array([[1., 1.], [1., 2.], [1., 3.],
              [1., 4.], [1., 5.]])
b = np.array([1., 2., 3., 3., 5.])

# Normal equations: (A^T A) x = A^T b
ATA = A.T @ A      # (2,2)
ATb = A.T @ b      # (2,)
x_star = np.linalg.solve(ATA, ATb)
print('Least-squares solution:', x_star)

# Verify: residual is orthogonal to columns of A
residual = b - A @ x_star
print('A^T * residual:', A.T @ residual)  # should be ~[0, 0]

# numpy built-in (more numerically stable via SVD)
x_lstsq, _, _, _ = np.linalg.lstsq(A, b, rcond=None)
print('lstsq solution:', x_lstsq)          # matches

The Gram-Schmidt Process

Given a set of linearly independent vectors {a₁, ..., aₖ}, Gram-Schmidt produces an orthonormal set {q₁, ..., qₖ} spanning the same subspace. The algorithm:

  1. q₁ = a₁ / ||a₁||
  2. For each i = 2, ..., k: a. Subtract projections onto all previous q vectors: vᵢ = aᵢ - Σⱼ<ᵢ (qⱼᵀaᵢ) qⱼ b. Normalize: qᵢ = vᵢ / ||vᵢ||

At each step, we remove the component of aᵢ that lies in the span of the previously processed vectors, leaving only the orthogonal complement. If vᵢ = 0, the vectors are linearly dependent.

import numpy as np

def gram_schmidt(A):
    """Gram-Schmidt orthonormalization. A: (m, k) columns to orthonormalize."""
    m, k = A.shape
    Q = np.zeros((m, k))
    for i in range(k):
        v = A[:, i].copy()
        # Subtract projections onto all previous orthonormal vectors
        for j in range(i):
            v -= np.dot(Q[:, j], v) * Q[:, j]
        norm = np.linalg.norm(v)
        if norm < 1e-10:
            raise ValueError(f'Column {i} is linearly dependent on previous columns')
        Q[:, i] = v / norm
    return Q

# Test
np.random.seed(0)
A = np.random.randn(5, 3)
Q = gram_schmidt(A)

# Verify orthonormality
print('QᵀQ (should be I):\n', np.round(Q.T @ Q, 6))
# Verify same column space
print('Rank check:', np.linalg.matrix_rank(np.hstack([A, Q])))  # should equal 3

QR Decomposition

Gram-Schmidt applied to the columns of a matrix A (m×n, m≥n, full column rank) produces the QR decomposition: A = QR, where: - Q (m×n): orthonormal columns (from Gram-Schmidt) - R (n×n): upper triangular with positive diagonal entries

R encodes the projection coefficients from Gram-Schmidt. QR is used for: - Solving linear systems: QR is more numerically stable than forming AᵀA (normal equations double the condition number) - Least squares: x = R⁻¹Qᵀb (backsubstitution + matrix-vector multiply) - Eigenvalue algorithms: QR iteration is the standard algorithm for computing all eigenvalues - Modified Gram-Schmidt*: A numerically more stable variant of classical Gram-Schmidt

import numpy as np

A = np.random.randn(5, 3)

# QR via numpy (Householder reflections, more stable than Gram-Schmidt)
Q, R = np.linalg.qr(A)
print('Q shape:', Q.shape)   # (5, 3) -- economy QR
print('R shape:', R.shape)   # (3, 3) -- upper triangular
print('R diagonal (positive):', np.diag(R))  # positive by convention
print('QᵀQ:', np.round(Q.T @ Q, 6))         # identity
print('Reconstruction error:', np.linalg.norm(A - Q @ R))  # ~1e-15

# Solve least squares via QR
b = np.random.randn(5)
# x* = R^{-1} Q^T b (backsubstitution)
x_qr = np.linalg.solve(R, Q.T @ b)
x_ref = np.linalg.lstsq(A, b, rcond=None)[0]
print('QR vs lstsq match:', np.allclose(x_qr, x_ref))

Orthogonal Initialization of Neural Networks

Initializing weight matrices with orthogonal matrices (randomly sampled from the set of orthogonal matrices using QR decomposition on a random Gaussian matrix) is a principled initialization strategy. Orthogonal matrices preserve input norms: ||Wx|| = ||x||, preventing both gradient explosion and vanishing at initialization.

Orthogonal initialization (Saxe et al., 2014) enables linear networks and deep linear networks to be trained efficiently. For nonlinear networks, it provides a strong initialization baseline, particularly for RNNs. PyTorch provides torch.nn.init.orthogonal_() which applies QR decomposition to generate the orthogonal matrix.

import torch
import torch.nn as nn

# Orthogonal initialization
linear = nn.Linear(128, 128)
nn.init.orthogonal_(linear.weight)   # Q from QR decomposition

# Verify orthogonality (approximately, for square weight)
W = linear.weight.data
print('WᵀW - I:', torch.norm(W.T @ W - torch.eye(128)).item())  # ~0

# Alternative: create orthogonal matrix manually
def orthogonal_matrix(n):
    G = torch.randn(n, n)
    Q, R = torch.linalg.qr(G)
    # Fix sign convention (ensure positive diagonal of R)
    Q = Q * torch.sign(torch.diag(R))
    return Q

Q = orthogonal_matrix(64)
print('Is orthogonal:', torch.allclose(Q.T @ Q, torch.eye(64), atol=1e-5))

[INFO] Orthogonal Regularization in GANs and Transformers

Orthogonal regularization adds a penalty ||WᵀW - I||_F² (or the soft version ||WᵀW - I||_F for non-square) to the loss, encouraging weight matrices to remain nearly orthogonal during training. This helps stabilize GAN training and has been used in Self-Attention GAN (SAGAN). For transformers, spectral normalization (constraining the largest singular value) achieves a related goal of controlling the Lipschitz constant.
