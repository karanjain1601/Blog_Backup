Bayesian Inference — Priors, Posteriors, and Likelihoods

Bayesian inference is a complete framework for learning from data: specify prior beliefs, observe data, update to posterior beliefs.

Bayesian vs Frequentist Philosophy

Frequentist: parameters are fixed unknowns; probability = long-run frequency.

Bayesian: parameters are random variables; probability = degree of belief.

Bayesian update: p(θ|D) ∝ p(D|θ) · p(θ)

Rational belief update (Cox's theorem): the only coherent way to update beliefs in the face of evidence.

Components

  • Prior p(θ): beliefs before data — informative, weakly informative, Jeffreys (p(θ) ∝ √|I(θ)|), or improper
  • Likelihood p(D|θ): model of data generation — same function MLE maximises
  • Posterior p(θ|D): full distribution over θ after observing D

Posterior Predictive Distribution

p(x|D) = ∫ p(x|θ) p(θ|D) dθ

Marginalises out parameter uncertainty — Bayesian model averaging over all plausible θ. Gives wider, better-calibrated intervals than plug-in estimators.

Marginal Likelihood (Evidence)

p(D) = ∫ p(D|θ) p(θ) dθ

Roles: (1) normalises the posterior; (2) model comparison via Bayes factors BF₁₂ = p(D|M₁)/p(D|M₂).

Usually intractable → motivates MCMC and variational inference.

Example: Bayesian Coin Flip

n flips, h heads. Prior: θ ~ Beta(α,β). Posterior: Beta(h+α, n−h+β)

Posterior mean: E[θ|data] = (h+α)/(n+α+β)

For small n: prior dominates (regularisation). For large n: converges to MLE h/n.

# Beta-Bernoulli conjugate update
h, n = flips.sum(), len(flips)
alpha_n, beta_n = alpha0 + h, beta0 + (n - h)
posterior_mean = alpha_n / (alpha_n + beta_n)
ci_low, ci_high = stats.beta.ppf([0.025, 0.975], alpha_n, beta_n)
# Posterior predictive P(next=heads|data) = posterior mean

Why Posteriors Are Hard

For non-conjugate models: high-dimensional, multi-modal, no closed form.

Approximation methods: - Laplace: Gaussian at MAP mode — fast but misses non-Gaussian features - MCMC: asymptotically exact, slow, convergence issues - Variational inference: fast, scalable, underestimates uncertainty - Expectation propagation: more accurate than VI, less scalable

Bayesian Neural Networks

Prior on weights W ~ N(0,I). Posterior p(W|D) over all networks consistent with data.

Approximation methods: - MC Dropout: dropout at test time ≈ Bernoulli variational posterior — cheapest - Deep Ensembles: K networks from different initialisations — empirically best calibration - Laplace Redux: MAP + Hessian approximation (KFAC) for posterior covariance - SWAG: Gaussian fit to SGD trajectory statistics
