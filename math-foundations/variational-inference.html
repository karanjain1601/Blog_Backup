Variational Inference and the ELBO

VI transforms intractable posterior computation into a tractable optimisation problem. It is the mathematical engine inside VAEs.

The Problem

p(z|x) = p(x|z)p(z)/p(x) where p(x) = ∫p(x|z)p(z)dz is intractable.

VI posits a tractable q(z;φ) and finds φ to minimise KL(q||p(z|x)).

KL Divergence

KL(q||p) = E_q[log q(z) − log p(z)] ≥ 0

  • Zero-forcing (mode-seeking): q avoids regions where p=0 → concentrates on one mode
  • NOT symmetric
  • KL(p||q) is zero-avoiding (mean-seeking) — used in expectation propagation

ELBO Derivation

log p(x) ≥ E_q[log p(x,z)] − E_q[log q(z)] = ELBO(q)

Equality holds when q = p(z|x). Gap = KL(q||p(z|x)).

Maximising ELBO ↔ minimising KL(q||p(z|x))

ELBO = E_q[log p(x|z)] − KL(q(z)||p(z)) = reconstruction quality − prior regularisation

Mean-Field CAVI

Assume q(z) = ∏ᵢ qᵢ(zᵢ). Optimal factor:

log q*ᵢ(zᵢ) = E_{q_{-i}}[log p(x,z)] + const

Coordinate ascent: iteratively update each factor while holding others fixed.

Amortised Inference — VAEs

Encoder neural network: x → (μ_φ(x), log σ²_φ(x)) — shared across all datapoints.

VAE ELBO: L(θ,φ;x) = E_{q_φ(z|x)}[log p_θ(x|z)] − KL(q_φ(z|x) || N(0,I))

KL term (analytic): KL = ½ Σⱼ(μⱼ² + σⱼ² − log σⱼ² − 1)

Reparameterisation trick: z = μ_φ(x) + σ_φ(x)⊙ε, ε~N(0,I) — makes z differentiable w.r.t. φ.

def reparameterise(mu, log_var):
    std = torch.exp(0.5 * log_var)
    eps = torch.randn_like(std)  # N(0,I) — independent of params
    return mu + eps * std        # differentiable path to z

def vae_loss(x, x_recon, mu, log_var):
    recon = F.binary_cross_entropy(x_recon, x, reduction='sum')
    kl = -0.5 * torch.sum(1 + log_var - mu.pow(2) - log_var.exp())
    return recon + kl  # negative ELBO

Black-Box VI

For non-conjugate models, estimate ELBO gradients via Monte Carlo:

∇_φ ELBO = E_q[∇_φ log q_φ(z) · (log p(x,z) − log q_φ(z))]

Score function estimator (REINFORCE) — high variance, mitigated by control variates. Reparameterisation trick gives lower-variance gradients for continuous distributions.

Key Failure Mode

VI (minimising KL(q||p)) underestimates posterior variance — overconfident. VAE posterior collapse: KL→0 (posterior equals prior, encoder carries no information). Mitigations: KL annealing, free bits, β-VAE.
